## 反向代理+证书管理

### 一、准备工作

#### 1.前情提要

- [x] 域名n8n.example.test已经解析到的本机的公网ipv6
- [x] cloudflare dns代理已关闭（灰色云朵）
- [x] n8n容器可以正常运行

#### 2.防火墙放行

需要使用**管理员**终端

```bash
# 放行80端口
netsh advfirewall firewall add rule name="nginx-http-ipv6" dir=in action=allow protocol=TCP localport=80
# 放行443端口
netsh advfirewall firewall add rule name="nginx-https-ipv6" dir=in action=allow protocol=TCP localport=443
```

### 二、修改docker-compose文件

#### 1.目录结构

```
automation
├── docker-compose.yml
├── .env
├── proxy/
│  ├─ acme-sh/                 acme-companion的acme.sh状态（账户+证书登记，持久化防重签）
│  ├─ certs/                   域名证书的放置目录
│  ├─ html/                    nginx和acme-companion的共享web目录，用于互联验证
│  └─ vhost/                   nginx站点配置文件的挂载目录
└─ ...（其他目录）
```

#### 2.`.env`文件

```
# 时区配置
TZ=Asia/Shanghai

# 域名配置
N8N_DOMAIN=n8n.example.test

# =n8n配置
N8N_WEBHOOK_URL=https://${N8N_DOMAIN}/

# 企业微信机器人 Webhook（如不需要可留空）
WECOM_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=

# acme-companion
# Let's Encrypt 通知邮箱（必须修改为真实邮箱）
DEFAULT_EMAIL=test@example.com
```

#### 3.`docker-compose.yml`

增加相应的nginx-proxy和acme-companion服务

```
services:

  nginx-proxy:
    image: nginxproxy/nginx-proxy
    container_name: nginx-proxy
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./proxy/html:/usr/share/nginx/html
      - ./proxy/certs:/etc/nginx/certs
      - ./proxy/vhost:/etc/nginx/vhost.d
      - /var/run/docker.sock:/tmp/docker.sock:ro
    labels:
    - "com.github.nginx-proxy.nginx=true"
    networks: [test]

  acme-companion:
    image: nginxproxy/acme-companion
    container_name: acme-companion
    restart: unless-stopped
    volumes:
      - ./proxy/html:/usr/share/nginx/html
      - ./proxy/certs:/etc/nginx/certs
      - ./proxy/vhost:/etc/nginx/vhost.d
      - ./proxy/acme-sh:/etc/acme.sh
      - /var/run/docker.sock:/var/run/docker.sock:ro
    environment:
      - DEFAULT_EMAIL=${DEFAULT_EMAIL}
    networks: [test]
    depends_on:
      - nginx-proxy

volumes:
  n8n_data:

networks:
  test:
```

### 三、启动服务

```bash
docker-compose up -d --build
```

### 四、验证

#### 1.查看日志

```bash
docker logs acme-companion   # 应显示证书签发成功
docker logs nginx-proxy      # 应无报错
```

#### 2.浏览器访问

访问 `https://n8n.303009.xyz`，地址栏应显示安全锁标志。

### 五、获取表单链接

1. 在 n8n 中打开工作流
2. 点击 `Form Trigger` 节点
3. 切换到 `Production URL`
4. 复制链接，格式为 `https://n8n.303009.xyz/form/xxx`

### 六、清理旧防火墙规则

```cmd
netsh advfirewall firewall delete rule name="n8n-5678"
```

### 七、架构总结

```
同事浏览器
    ↓
https://n8n.303009.xyz/form/xxx
    ↓
Cloudflare DNS（仅解析，不代理）
    ↓
Windows 防火墙（放行 80/443）
    ↓
nginx-proxy（监听 80/443，自动申请 SSL）
    ↓
n8n 容器（内网 5678 端口，不对外暴露）
    ↓
Form Trigger → 处理上传 → 钉钉消息
```
