## Windows环境配置使用Docker

> [!NOTE]
>
> 本次示例Windows环境是win11 23h2，选择了Docker Desktop



> [!CAUTION]
>
> 本文原编写于2025，目前发布之时还未重新验证



---

### 1.启用Windows功能

以**管理员身份**打开powershell（win+x选择终端管理员），依次执行以下命令：

```powershell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
```

```powershell
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

执行完毕后。重启电脑

### 2.安装并配置WSL 2

- **下载WSL 2 Linux内核更新包**，访问[Microsoft官方更新包下载页](https://learn.microsoft.com/zh-cn/windows/wsl/install-manual#step-4---download-the-linux-kernel-update-package)，下载并运行`wsl_update_x64.msi`文件。

- **设置WSL 2为默认版本**：再次以管理员身份打开powershell，执行：

  ```powershell
  wsl --set-default-version 2
  ```

- **安装一个Linux发行版**：打开Microsoft Store，搜索并安装一个Linux发行版，例如Ubuntu。首次启动时需要你设置用户名和密码。
  此次学习，用户名设置为ubuntu，密码设置为ubuntu

### 3.安装Docker Desktop

- **下载安装程序**：前往[Docker官网](https://www.docker.com/products/docker-desktop/)下载Docker Desktop for Windows安装包。判断cpu是什么架构，如果是intel/amd，选择amd64版本；如果是arm架构的芯片（例如高通骁龙系列），选择arm64版本。

- **运行安装**：双击下载的`Docker Desktop Installer.exe`，在安装向导中，**务必勾选"使用 WSL 2 而不是 Hyper-V"的选项**，然后按提示完成安装。

- **指定位置安装**：使用命令可指定位置安装

  ```cmd
  start /w "" "Docker Desktop Installer.exe" install --installation-dir=D:/WSL/Docker
  ```

- **首次启动**：安装完成后启动Docker Desktop，它会提示你接受服务条款。之后，Docker会自动完成初始设置。

### 4.验证安装与基础配置

安装完成后，建议进行以下操作来确认一切正常。

- **验证安装**：打开命令行（cmd或者powershell），输入以下命令：

  ```bash
  docker --version
  ```

  如果成功显示版本号，说明Docker已正确安装。接着运行经典的测试容器：

  ```bash
  docker run hello-world
  ```

  如果能看到欢迎信息，则证明你的 Docker 已经可以正常运行了（倘若未配置镜像加速器，那么可能因为无法访问Docker Hub官方仓库，这是正常的，配置镜像加速器即可避免）。

- 配置镜像加速器（推荐）：在国内，从Docker Hub拉取镜像可能会比较慢，建议配置国内镜像源以提升下载速度。

  - 右键点击系统托盘（右下角）的 Docker 图标，选择 "Settings"。

  - 进入 **Docker Engine** 选项卡。

  - 在配置 JSON 文件中，找到或添加 `"registry-mirrors"` 项，填入可用的国内镜像地址，例如：

    ```json
    {
      "builder": {
        "gc": {
          "defaultKeepStorage": "20GB",
          "enabled": true
        }
      },
      "experimental": false,
      "registry-mirrors": [
        "https://docker.1ms.run",
        "https://docker.xuanyuan.me",
        "https://docker.m.daocloud.io",
        "https://docker-0.unsee.tech",
        "https://registry-1.docker.io"
      ]
    }
    ```

  - 点击 "Apply & Restart" 使配置生效并重启 Docker 服务。

  - 验证配置：终端使用`docker info`命令，在输出信息中查找“Registry Mirrors”的部分，确认配置的镜像源地址已经出现在列表中

  - 实际测试：用 `time docker pull [镜像名]` 测试不同源的实际速度，还可以调整源顺序

### 5.常见问题与解决

- **Docker Desktop 无法启动或闪退**：
  - 确保已严格完成上述所有准备步骤，尤其是启用Windows功能和安装WSL 2更新包。
  - 可以尝试在命令行中运行 `netsh winsock reset` 后重启电脑。
  - 有时删除Docker的配置文件（路径为 `C:\Users\用户名\AppData\Roaming\Docker\settings.json`）并重新启动也可能解决问题。
- **Docker 命令提示权限不足**：
  - 确保你用于运行命令的用户账户拥有管理员权限。
  - 或者在安装过程中，Docker Desktop 是否已自动将你的用户添加到 `docker-users` 组中，如果没有，可以手动添加。
- **镜像拉取失败或速度慢**：
  - 这通常是网络问题，请务必检查并正确配置上述的**镜像加速器**。

### 6.迁移数据释放c盘空间

#### （1）使用WSL命令迁移（推荐，更彻底）

这种方法功能强大，可以分别迁移Ubuntu系统和Docker的数据。

1. **准备工作**：以**管理员身份**打开Windows PowerShell。
2. **查看已安装的发行版**：执行 `wsl -l -v` 命令，查看当前已安装的WSL发行版及其状态。
3. **停止相关服务**：在执行操作前，请确保通过右键点击系统托盘的Docker图标退出Docker Desktop，并运行 `wsl --shutdown` 以确保所有WSL发行版都已关闭。

| 命令名称         | 具体命令              | 主要作用和输出示例                                           |
| :--------------- | :-------------------- | :----------------------------------------------------------- |
| **标准版本查询** | `lsb_release -a`      | 显示最完整的版本信息，包括**版本号 (Release)** 和 **代号 (Codename)**。例如：`Ubuntu 22.04 LTS`，代号 `jammy`。 |
| **系统信息查看** | `cat /etc/os-release` | 显示系统详细的识别数据，信息全面易读，也会包含版本号和友好名称。 |
| **快速版本查看** | `cat /etc/issue`      | 快速查看系统版本号，输出非常简洁，例如：`Ubuntu 22.04 LTS \n \l`。 |
| **内核版本查询** | `uname -r`            | 主要用于查看**Linux内核版本**，例如：`5.15.0-78-generic`。   |

接下来，您可以迁移Ubuntu系统或Docker数据：

- **迁移Ubuntu系统**：
  - **导出**：将当前的Ubuntu系统打包成一个文件，例如 `wsl --export Ubuntu-22.04 D:\WSL\Ubuntu22.04.tar`。
  - **注销**：删除当前位于C盘的Ubuntu系统以释放空间，执行 `wsl --unregister Ubuntu-22.04`。
  - **导入**：在目标位置（如D盘）重新导入刚才的备份文件，例如 `wsl --import Ubuntu-22.04 D:\WSL\Ubuntu D:\WSL\Ubuntu22.04.tar --version 2`。之后即可删除备份的`.tar`文件。
- **迁移Docker数据**：
  - Docker的数据主要存储在名为 `docker-desktop-data` 的发行版中。
  - 流程与迁移Ubuntu类似：先**导出**（`wsl --export docker-desktop-data D:\docker-desktop-data.tar`），然后**注销**（`wsl --unregister docker-desktop-data`），最后再**导入**到新位置（`wsl --import docker-desktop-data D:\docker\wsl D:\docker-desktop-data.tar --version 2`）。



#### （2）通过Docker Desktop图形界面迁移

这个方法更为简单直观，但主要适用于迁移Docker的镜像存储位置。

1. **找到设置**：右键点击任务栏的Docker图标，选择 "Settings"。
2. **修改路径**：进入 **"Resources"** 下的 **"Advanced"** 设置。在这里你会找到 **"Disk image location"**，点击 "Browse" 即可将其更改到其他磁盘（例如D盘）。
3. **应用设置**：点击 "Apply & Restart"，Docker会自动完成重启和数据迁移。
