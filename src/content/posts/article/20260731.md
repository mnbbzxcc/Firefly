## Windows环境搭建真实的Linux系统Ubuntu

> [!NOTE]
>
> 本次示例Windows环境是win11 23h2，Linux系统选择Ubuntu系统

---

### 一、准备

#### 1.虚拟机软件

- 选择一：**VMware Workstation Pro**
  - [官方网址](https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion)
- 选择二：**VirtualBox**
- 选择三：**Hyper-V**

> 本次使用的是VMware Workstation Pro，其已免费，官网即可下载（需登录），自行安装。

#### 2.**Ubuntu ISO镜像**

推荐**Ubuntu 22.04 LTS**或**Ubuntu 24.04 LTS**，LTS代表长期支持版，更稳定可靠。

- 下载：
  - [Ubuntu官网下载地址](https://ubuntu.com/download/desktop)
  - 国内镜像下载（加快下载速度）
    - [阿里云镜像站](https://mirrors.aliyun.com/ubuntu-releases/)
    - [中科大镜像站](https://mirrors.ustc.edu.cn/ubuntu-releases/)
- 文件类型：
  - `ubuntu-24.04.4-desktop-amd64.iso`桌面版镜像
  - `ubuntu-24.04.4-live-server-amd64.iso`服务器镜像

> - 本次示例在中科大镜像站下载，两种镜像均下载，先学习服务器镜像的搭建。
> - amd64适用于主流64位（x86-64架构，也称作x64）的电脑

### 二、创建安装虚拟机

#### 操作流程

1. 创建新虚拟机：打开Vmware，点击`创建新的虚拟机`

![](./20260731/1.png)

2. 选择配置类型：`自定义`（更好地掌握硬件配置）

![](./20260731/2.png)

3. 虚拟机硬件兼容性：保持默认即可

![](./20260731/3.png)

4. 选择安装来源：`稍后安装操作系统`

![](./20260731/4.png)

5. 选择客户机操作系统：客户机操作系统选择`Linux`，版本选择`Ubuntu 64位`

![](./20260731/5.png)

6. 设定虚拟机名称并且选定虚拟机位置（更改名称尽量不带中文，尽量选择D盘，避免C盘空间不足）

![](./20260731/6.png)

7. 配置处理器：根据电脑的CPU性能分配，建议**至少2核**

![](./20260731/7.png)

8. 配置内存：**学习开发建议4-8GB**，经验法则是不超过宿主机物理内存的一半

![](./20260731/8.png)

9. 配置网络：`使用网络地址转换(NAT)`

![](./20260731/9.png)

10. 选择I/O控制器类型：默认即可

![](./20260731/10.png)

11. 选择磁盘类型：默认即可

![](./20260731/11.png)

12. 选择磁盘：`创建新虚拟磁盘`

![](./20260731/12.png)

13. 指定磁盘容量：默认`20GB`即可（后续可以自行更改）

![](./20260731/13.png)

14. 指定磁盘文件：默认即可

![](./20260731/14.png)

15. 确认信息无误

![](./20260731/15.png)

16. 虚拟机外壳已经创建完毕

![](./20260731/16.png)

17. 虚拟机挂载镜像

- 在VMware主界面选中刚创建的虚拟机，点击“编辑虚拟机设置”。
- 在设置中，选择“CD/DVD (SATA)”，右侧勾选“使用ISO映像文件”，点击“浏览”选择下载好的Ubuntu ISO镜像文件。
- 点击“确定”保存。

![](./20260731/17.png)

### 三、安装系统

1. 启动虚拟机
2. 开始安装：虚拟机启动后，会从ISO镜像引导。在引导菜单上，选择`Try or Install Ubuntu Server`，回车确认

![](./20260731/18.png)

3. 调整虚拟机查看方式

> 不明原因导致字体看起来极小，看起来费劲，调整虚拟机查看方式便于查看

![](./20260731/19.png)

4. 语言：默认的`English`，回车确认

![](./20260731/20.png)

5. 提示有更新版本，无需更新（下载速度慢），`Continue without Updating`即可，回车确认

![](./20260731/21.png)

6. 键盘布局：默认的`English(US)`

![](./20260731/22.png)

7. 安装类型：`Ubuntu Server`

![](./20260731/23.png)

8. 网络配置：保持默认即可

> 此处不一定是192.168.10.130，按照其默认配置好的即可

![](./20260731/24.png)

9. 代理：留空

![](./20260731/25.png)

10. 软件源：默认

> 可能是因为在镜像站下载的缘故，自动填充了软件源，不必改动

![](./20260731/26.png)

11. 磁盘分区：`Use an entire disk`

> 此处都保持默认即可

![](./20260731/27.png)

12. 分区详情

> 已自动分区，可不改

![](./20260731/28.png)

13. 确认分区：`continue`

> 这是一个确认的警告，将会对虚拟化硬盘进行格式化，这是正常搭建流程，继续即可

![](./20260731/29.png)

14. 设置用户信息：

- **Your name**: 全名（可以随意）
- **Your server's name**: 主机名
- **Pick a username**: 用户名（用于登录）
- **Choose a password**: 密码
- **Confirm your password**: 再次输入密码

> ubuntu设定一个用户名，即创建一个普通用户，避免root权限登录

![](./20260731/30.png)

15. 更新至pro：`Skip for now`

![](./20260731/31.png)

16. 安装OpenSSH Server：`Install OpenSSH server`

> [!CAUTION]
>
> 最好要安装，方便ssh远程连接

![](./20260731/32.png)

17. 等待安装完成，看到`Installation complete`的提示后，选择`Reboot Now`并回车重启

![](./20260731/33.png)

18. 移除安装介质：虚拟机重启会再次从ISO镜像启动吗，会出现如下报错，无视并回车即可

![](./20260731/34.png)

> [!NOTE]
>
> 虚拟机关机后取消勾选启动时连接ISO镜像，即可避免报错
>
> ![](./20260731/35.png)

### 四、系统使用

#### 1.登录系统

 上述都完成后再启动系统，将会出现`login:`提示，输入设置的用户名和密码，就可以进入Ubuntu的命令行

![](./20260731/36.png)

> [!NOTE]
>
> - 输入密码时不会显示密码输入状态，输入错误就多按退格完全重新输入（Linux的安全设置如此）
>
> - 本次示例用户名设置为`user`，密码设置为`123456`，真实的生产环境绝对不要设置简单密码

#### 2.查找IP地址

```bash
# 查找IP
ip address

# 或者简写
ip add

# 以下简写亦可
ip a
```

可以看到对应的IP地址

![](./20260731/37.png)

> - 本次示例的ip地址为192.168.10.130，并不确保每次相同，需要自查
> - 获取ip地址是为了后续使用远程连接

#### 3.测试联网

 使用以下命令测试联网

```bash
# 测试联网
ping -c 10 baidu.com
```

![](./20260731/38.png)

#### 4.软件源

```bash
# 查看软件源
cat /etc/apt/sources.list.d/ubuntu.sources
```

![](./20260731/39.png)

> 目前已经是中国源了，安全更新的源依旧是国外源，但是使用频率低，可以暂时不管

### 五、远程连接

#### 4.更新系统软件包

```bash
# 更新所有自带软件到最新版
sudo apt update && sudo apt upgrade -y
```

> 看到提示时，按`Y`继续（因为加了`-y`会自动确认）。

#### 5.安装常用软件包

```bash
sudo apt install vim net-tools curl wget git tree htop -y
```

- `vim`：比自带的`vi`好用的文本编辑器
- `net-tools`：提供`ifconfig`等经典网络命令
- `curl/wget`：下载文件使用
- `git`：版本控制所需
- `tree`：以树形结构显示目录
- `htop`：更漂亮的任务管理器

#### 6.配置防火墙

```bash
# 先允许SSH端口
sudo ufw allow ssh
# 再开启防火墙
sudo ufw enable
```

输入 `y` 确认。以后如果要开其他端口（比如 8080），再用 `sudo ufw allow 8080` 即可。

#### 7.保存干净状态（快照）

```bash
# 关闭虚拟机
sudo shutdown -h now
```

在 VMware 主界面，右键虚拟机 -> 快照 -> 拍摄快照取名 `初始干净环境`。

### 六、后期使用

#### 1.硬盘扩容

先在VMware把硬盘物理调大，再进Ubuntu系统把多余的空间划给分区

（1）VMware中扩展硬盘容量

```bash
# 关闭虚拟机
sudo shutdown -h now
```

- 编辑硬件设置：在 VMware 主界面，右键虚拟机 -> “设置”。

- 找到硬盘并扩展：

  - 选择 “硬盘 (SCSI)”。

  - 点击下方的 “扩展” 按钮（Utilities -> Expand）。

  - 在弹出的窗口里，输入你想要的总容量（例如，从 20GB 改为 40GB）。

  - 点击“扩展”，等待进度条走完（只需几秒钟）。

- 开机：扩展完成后，重新启动虚拟机，用 FinalShell 连回去。

（2）Ubuntu中识别并分配新空间

连上 SSH 后，先执行 `lsblk` 查看磁盘结构。你会看到类似下面的输出（重点看 `sda` 和 `ubuntu-vg`）：

```
NAME                      MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
sda                         8:0    0   40G  0 disk
├─sda1                      8:1    0    1G  0 part /boot
├─sda2                      8:2    0    2G  0 part [SWAP]
└─sda3                      8:3    0   37G  0 part
  └─ubuntu--vg-ubuntu--lv 253:0    0   19G  0 lvm  /
```

（注意：虽然 `sda` 现在显示为 40G，但 `ubuntu--vg-ubuntu--lv` 还是只有 19G，多出来的空间还没用上。）

#### 方案一：标准 LVM 扩容（大概率适用，一条命令搞定）

如果你看到上面的 `lvm` 字样，说明系统用了 LVM。执行下面这条**终极命令**，它会自动把剩余所有空闲空间都分配给根目录：

bash

```
sudo lvextend -r -l +100%FREE ubuntu-vg/ubuntu-lv
```



*（注意：如果系统提示 Volume group "ubuntu-vg" not found，请先执行 `vgdisplay` 查看实际的 VG 名称，通常是 `ubuntu-vg`，把命令里的名字替换掉即可）*

- `-r`：自动调整文件系统大小，不用再手动敲 `resize2fs`。
- `-l +100%FREE`：把卷组里所有的空闲空间都拿来。

执行完后，直接跳到最后一步检查结果。

------

#### 📌 方案二：标准分区扩容（如果方案一报错）

如果方案一报错，说明你当初安装时选了“不使用 LVM”的传统分区。这时操作稍麻烦一点，但也很简单：

1. **安装扩容工具**（如果没装）：

   bash

   ```
   sudo apt install cloud-guest-utils -y
   ```

   

2. **查看根分区挂在哪个分区上**：

   bash

   ```
   df -h /
   ```

   

   如果显示 `/dev/sda3`，就说明根分区在 `sda3` 上。

3. **扩展分区表**：

   bash

   ```
   sudo growpart /dev/sda 3
   ```

   

   *（注意 `sda` 和 `3` 之间有空格）*

4. **扩展文件系统**：

   bash

   ```
   sudo resize2fs /dev/sda3
   ```

   

------

✅ 第三步：验证扩容结果

无论用哪种方案，最后执行：

bash

```
df -h /
```

如果看到 `/` 目录的容量已经变成了新的 40G（或你设定的值），就说明大功告成了！
