## Windows环境搭建真实的Linux系统Ubuntu

> [!NOTE]
>
> 本次示例Windows环境是win11 23h2，Linux系统选择Ubuntu系统

---

### 一、准备

#### 1.虚拟机软件

- 选择一：**VMware Workstation Pro**
  - [官方网址](https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion)
- 选择二：**VirtualBox**
- 选择三：**Hyper-V**

> 本次使用的是VMware Workstation Pro，其已免费，官网即可下载（需登录），自行安装。

#### 2.**Ubuntu ISO镜像**

推荐**Ubuntu 22.04 LTS**或**Ubuntu 24.04 LTS**，LTS代表长期支持版，更稳定可靠。

- 下载：
  - [Ubuntu官网下载地址](https://ubuntu.com/download/desktop)
  - 国内镜像下载（加快下载速度）
    - [阿里云镜像站](https://mirrors.aliyun.com/ubuntu-releases/)
    - [中科大镜像站](https://mirrors.ustc.edu.cn/ubuntu-releases/)
- 文件类型：
  - `ubuntu-24.04.4-desktop-amd64.iso`桌面版镜像
  - `ubuntu-24.04.4-live-server-amd64.iso`服务器镜像

> - 本次示例在中科大镜像站下载，两种镜像均下载，先学习服务器镜像的搭建。
> - amd64适用于主流64位（x86-64架构，也称作x64）的电脑

### 二、创建安装虚拟机

#### 操作流程

1. 创建新虚拟机：打开Vmware，点击`创建新的虚拟机`

![](./20260731/1.png)

2. 选择配置类型：`自定义`（更好地掌握硬件配置）

![](./20260731/2.png)

3. 虚拟机硬件兼容性：保持默认即可

![](./20260731/3.png)

4. 选择安装来源：`稍后安装操作系统`

![](./20260731/4.png)

5. 选择客户机操作系统：客户机操作系统选择`Linux`，版本选择`Ubuntu 64位`

![](./20260731/5.png)

6. 设定虚拟机名称并且选定虚拟机位置（更改名称尽量不带中文，尽量选择D盘，避免C盘空间不足）

![](./20260731/6.png)

7. 配置处理器：根据电脑的CPU性能分配，建议**至少2核**

![](./20260731/7.png)

8. 配置内存：**学习开发建议4-8GB**，经验法则是不超过宿主机物理内存的一半

![](./20260731/8.png)

9. 配置网络：`使用网络地址转换(NAT)`

![](./20260731/9.png)

10. 选择I/O控制器类型：默认即可

![](./20260731/10.png)

11. 选择磁盘类型：默认即可

![](./20260731/11.png)

12. 选择磁盘：`创建新虚拟磁盘`

![](./20260731/12.png)

13. 指定磁盘容量：默认`20GB`即可（后续可以自行更改）

![](./20260731/13.png)

14. 指定磁盘文件：默认即可

![](./20260731/14.png)

15. 确认信息无误

![](./20260731/15.png)

16. 虚拟机外壳已经创建完毕

![](./20260731/16.png)

17. 虚拟机挂载镜像

- 在VMware主界面选中刚创建的虚拟机，点击“编辑虚拟机设置”。
- 在设置中，选择“CD/DVD (SATA)”，右侧勾选“使用ISO映像文件”，点击“浏览”选择下载好的Ubuntu ISO镜像文件。
- 点击“确定”保存。

![](./20260731/17.png)

### 三、安装系统

1. 启动虚拟机
2. 开始安装：虚拟机启动后，会从ISO镜像引导。在引导菜单上，选择`Try or Install Ubuntu Server`，回车确认

![](./20260731/21.png)

![](./20260731/22.png)

7. 安装类型：`Ubuntu Server`

![](./20260731/23.png)

8. 网络配置：保持默认即可

> 此处不一定是192.168.10.130，按照其默认配置好的即可

![](./20260731/24.png)

9. 代理：留空

![](./20260731/25.png)

10. 软件源：默认

> 可能是因为在镜像站下载的缘故，自动填充了软件源，不必改动

![](./20260731/26.png)

11. 磁盘分区：`Use an entire disk`

> 此处都保持默认即可

![](./20260731/27.png)

12. 分区详情

> 已自动分区，可不改

![](./20260731/28.png)

13. 确认分区：`continue`

> 这是一个确认的警告，将会对虚拟化硬盘进行格式化，这是正常搭建流程，继续即可

![](./20260731/29.png)

14. 设置用户信息：

- **Your name**: 全名（可以随意）
- **Your server's name**: 主机名
- **Pick a username**: 用户名（用于登录）
- **Choose a password**: 密码
- **Confirm your password**: 再次输入密码

> ubuntu设定一个用户名，即创建一个普通用户，避免root权限登录

![](./20260731/30.png)

15. 更新至pro：`Skip for now`

![](./20260731/31.png)

16. 安装OpenSSH Server：`Install OpenSSH server`

> [!CAUTION]
>
> 最好要安装，方便ssh远程连接

![](./20260731/32.png)

17. 等待安装完成，看到`Installation complete`的提示后，选择`Reboot Now`并回车重启

![](./20260731/33.png)

![](./20260731/34.png)

### 五、远程连接

#### 1.`SSH`远程概述

- `SSH`(Secure Shell)，即为安全外壳协议，这是一种网络协议，用在不安全的网络环境中，安全地远程登录到另一台计算机并执行命令。SSH默认使用`TCP端口22`进行通信。

- SSH出现之前常用的远程登录协议是`Telnet`，但是其数据（用户名、密码等）均是明文传输， 容易被截获数据包，不安全。
- SSH连接的优势：
  - 传输加密，防窃听
  - 身份验证机制完善
    - 密码登录：常用，输入用户名和密码即可
    - 密钥登录：更安全，公钥和私钥配对即可
  - 支持端口转发和隧道
  - 内置安全的文件传输
  - 跨平台兼容性好
  - 连接稳定，支持会话保持

实用性来说，使用远程连接可以获得：

1. 更舒适的字体和配色
2. 完美的复制粘贴支持
3. 文件管理面板（可视化拖拽）

> 本次示例使用FinalShell做远程连接

#### 2.完成远程连接

[FinalShell官方网址](https://www.hostbuf.com/)

### 六、常用操作

#### 1.更新系统软件包

```bash
# 更新所有自带软件到最新版
sudo apt update && sudo apt upgrade -y
```

> 加了`-y`会自动确认，添加sudo因为需要root权限执行

下图即更新完成

![44](./20260731/44.png)

#### 2.安装常用软件包

```bash
sudo apt install vim net-tools curl wget git tree htop -y
```

- `vim`：比自带的`vi`好用的文本编辑器
- `net-tools`：提供`ifconfig`等经典网络命令
- `curl/wget`：下载文件使用
- `git`：版本控制所需
- `tree`：以树形结构显示目录
- `htop`：更漂亮的任务管理器

#### 3.配置防火墙

```bash
# 先允许SSH端口
sudo ufw allow ssh
# 再开启防火墙
sudo ufw enable
```

输入 `y` 确认。以后如果要开其他端口（比如 8080），再用 `sudo ufw allow 8080` 即可。

#### 4.快照

- VMware快照是一种为虚拟机在特定时间点拍摄的状态存档。就像是电脑游戏里的“存档点”，可以完整记录下那一刻虚拟机的所有信息：
  - 状态(State)：虚拟机的电源状态，比如是开机、关机还是挂起。
  - 数据(Data)：构成虚拟机的所有文件，包括虚拟磁盘（VMDK）、内存数据以及各种设备配置。
- 快照常用于：
  - 系统更新与补丁安装
  - 软件测试与开发
  - 故障排查
  - 作为临时还原点
- 快照工作原理简述：创建快照，原始磁盘文件`-flat.vmdk`变为只读；后续更改写入增量磁盘`-delta.vmdk`中，读取时系统会只能合并呈现出最新状态；删除快照时候把增量磁盘中的数据写回到原始磁盘，复制完成后删除增量文件（*需要额外空间合并*）

```bash
# 关闭虚拟机
sudo shutdown -h now
```

选定虚拟机右键，点击`快照`，再点击`拍摄快照`

![](./20260731/45.png)

填写名称，可选填写描述，即可拍摄快照

![](./20260731/46.png)

### 七、后期可能需要

#### 1.硬盘扩容

先在VMware把硬盘物理调大，再进Ubuntu系统把多余的空间划给分区

（1）VMware中扩展硬盘容量

```bash
# 关闭虚拟机
sudo shutdown -h now
```

- 编辑硬件设置：在 VMware 主界面，右键虚拟机，点击`设置`。

- 找到硬盘并扩展：

  - 点击`硬盘 (SCSI)`

  - 点击`扩展”`

  - 在弹出的窗口里，输入你想要的总容量（例如，从20GB改为25GB）

  - 点击`扩展`，等待完成

- 开机：扩展完成后，重新启动虚拟机，用finalshell连回。

![](./20260731/47.png)

> 如果扩展按钮是灰色无法选择，可能是留存有快照，需先删除

（2）Ubuntu中识别并分配新空间

```bash
# 查看磁盘结构
lsblk
```

![](./20260731/48.png)

> 明显本次示例系统使用LVM。虽然`sda`现在显示25G，但`ubuntu--vg-ubuntu--lv`还是只有10G，原先就有8.2G空闲空间，现在增加的5G还没有划入`sda3`分区，LVM还没能查到

##### LVM扩容

```bash
# 扩展分区表（示例系统已装growpart）
sudo growpart /dev/sda 3
```

![](./20260731/49.png)

```bash
# 扩展物理卷
sudo pvresize /dev/sda3
```

![](./20260731/50.png)

```bash
# 检查卷组（VG）当前空间
sudo vgdisplay
```

![](./20260731/51.png)

```bash
# 分配8G空闲空间给根目录
sudo lvextend -r -L +8G /dev/ubuntu-vg/ubuntu-lv
# 分配所有空闲空间给根目录
sudo lvextend -r -l +100%FREE /dev/ubuntu-vg/ubuntu-lv
```

> [!NOTE]
>
> 如果系统提示 Volume group "ubuntu-vg" not found，请先执行 `vgdisplay` 查看实际的 VG 名称，通常是 `ubuntu-vg`，把命令里的名字替换掉即可

- `-r`：自动调整文件系统大小，不用再手动敲`resize2fs`
- `-l +100%FREE`：把卷组里所有的空闲空间都拿来。

![](./20260731/52.png)

##### 标准扩容

```bash
# 安装扩容工具
sudo apt install cloud-guest-utils -y
```

```bash
# 检查分区位置
df -h /
```

如果显示 `/dev/sda3`，就说明根分区在 `sda3` 上。

```bash
# 扩展分区表
sudo growpart /dev/sda 3
```

```bash
# 扩展文件系统
sudo resize2fs /dev/sda3
```

##### 检查扩容结果

```bash
# 检查扩容结果
df -h /
```

![](./20260731/53.png)

> 层级关系：物理硬盘 (`sda`) → 物理分区 (`sda3`) → 物理卷 (PV) → 卷组 (VG `ubuntu-vg`) → 逻辑卷 (LV `ubuntu-lv`) → 挂载点 (`/`)
