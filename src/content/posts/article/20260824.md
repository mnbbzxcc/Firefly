## playwright模拟人类操作

### 环境准备

- 安装python
- 安装playwright

```bash
# 检查python环境
python --version
# 或者
python3 --version

# 安装playwright库
pip install playwright
# 国内镜像源下载较快
pip install playwright -i https://pypi.tuna.tsinghua.edu.cn/simple

# 安装浏览器驱动（国内镜像下载速度较快）
set PLAYWRIGHT_DOWNLOAD_HOST=https://registry.npmmirror.com/-/binary/playwright
playwright install
```

### 简单测试

创建python脚本first_test.py
```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    # 启动浏览器，故意放慢速度方便观察（slow_mo=500 毫秒/步）
    browser = p.chromium.launch(headless=False, slow_mo=500)
    page = browser.new_page()
    
    # 访问百度
    page.goto("https://www.baidu.com")
    
    # 等待搜索框出现（最多等待10秒）
    page.wait_for_selector("#kw", timeout=10000)
    # 输入文字
    page.fill("#kw", "Playwright")
    
    # 等待搜索按钮出现
    page.wait_for_selector("#su", timeout=10000)
    # 点击搜索
    page.click("#su")
    
    # 等待搜索结果出现（确保搜索完成）
    page.wait_for_selector("#content_left", timeout=10000)
    
    # 停留 3 秒让你看清结果
    page.wait_for_timeout(3000)
    
    # 关闭浏览器
    browser.close()
```
运行脚本测试
```
python first_test.py
```
