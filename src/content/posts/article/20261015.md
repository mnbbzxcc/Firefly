## sheet拆分 · vba快速版

1. excel已保存状态并打开

2. 按`Alter`+`F11`打开vba编辑器

3. 点击`插入`，选择`模块`

4. 粘贴以下代码

   ```vba
   Sub 自适应拆分所有工作表为独立工作簿()
       Dim ws As Worksheet
       Dim newWb As Workbook
       Dim savePath As String
       Dim fileName As String
       Dim baseName As String
       Dim badChars As Variant
       Dim i As Long, n As Long, k As Long
   
       ' 当前工作簿必须先保存
       If ThisWorkbook.Path = "" Then
           MsgBox "请先保存当前工作簿，再运行此宏。"
           Exit Sub
       End If
   
       savePath = ThisWorkbook.Path & Application.PathSeparator
       badChars = Array("\", "/", ":", "*", "?", "[", "]")
   
       Application.ScreenUpdating = False
       Application.DisplayAlerts = False
   
       For Each ws In ThisWorkbook.Worksheets
   
           ' 如果只想拆“可见工作表”，取消下面这行注释
           ' If ws.Visible <> xlSheetVisible Then GoTo NextSheet
   
           ' 复制当前工作表到新工作簿
           ws.Copy
           Set newWb = ActiveWorkbook
   
           ' 用工作表名作为文件名
           baseName = ws.Name
   
           ' 替换文件名不允许的字符
           For i = LBound(badChars) To UBound(badChars)
               baseName = Replace(baseName, badChars(i), "_")
           Next i
   
           ' 如果同名文件已存在，自动加序号，避免覆盖
           fileName = baseName
           k = 1
           Do While Dir(savePath & fileName & ".xlsx") <> ""
               k = k + 1
               fileName = baseName & "_" & k
           Loop
   
           ' 保存为 xlsx
           newWb.SaveAs fileName:=savePath & fileName & ".xlsx", _
                        FileFormat:=xlOpenXMLWorkbook
   
           newWb.Close SaveChanges:=False
           n = n + 1
   
   NextSheet:
       Next ws
   
       Application.DisplayAlerts = True
       Application.ScreenUpdating = True
   
       MsgBox "拆分完成，共生成 " & n & " 个工作簿。" & vbCrLf & _
              "保存位置：" & savePath
   End Sub
   ```

5. 点击`F5`执行

6. 同文件夹下即可见已拆分完毕的工作簿

> VBA知识拓展：
>
> - VBA全程Visual Basic for Applications，是微软office中自带的编程语言，无需额外安装即可在office套件中使用
> - 常用快捷键：
>   - `Alt`+`F11`：打开 VBA 编辑器
>   - `Alt`+`F8`：查看和运行宏
>   - `F5`：运行当前过程
>   - `F8`：单步执行，调试用
>   - `Ctrl`+`G`：打开“立即窗口”，可临时测试代码
>   - `F9`：加断点
